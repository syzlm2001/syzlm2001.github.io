01

从光谱输入到持续注册

STEP 01光谱质控

完成吸光度转换、重复扫描聚合与物理样本分组。

STEP 02未知风险触发

识别训练外样本和模型高误接受风险。

STEP 03人工确认

请求高价值标签并更新当前可见标签池。

STEP 04专家注册

按标签预算训练新类别专家并通过质量门控。

STEP 05决策输出

统一路由类别、比例、冲突证据与风险动作。

02

持续学习算法与 Agent 分工

MODELING AGENTS

训练、策略和验收职责分离

以 ModelingPipeline 编排 DataAudit、Training、Strategy 和 Acceptance 四类 Agent，完成元数据审计、候选训练、OOF 评估、策略选择和独立验收。策略推理异常时按确定性 OOF 规则回退。

SHARED ARBITRATOR

共享多类别仲裁器处理专家冲突

在基础模型与多个新类别专家之间建立统一仲裁，综合专家置信度、未知状态和分类结果，处理新类别之间以及新旧类别之间的竞争。

SEQUENTIAL REGISTRATION

新类别按实际到达顺序接入

仅使用当前已确认标签，在 R3、R6、R12、R24 嵌套预算下更新专家。两个类别以两种顺序到达时均完成连续注册，训练状态与标签可见时间完整记录。

JOINT ROUTING

类别与比例联合学习进入统一路由

组合共享仲裁、专家注册表、类别预测头和比例预测头，为每个样本输出类别、掺假比例、置信度、路由来源、候选专家和冲突证据。

03

从基础建模到持续学习增益

BASE MODEL

物理样本级验证控制数据泄漏

基础建模覆盖 972 条光谱、324 个物理样本和 1,948 维特征，按物理样本分组完成候选模型比较与跨批次评价。RF/SNV 达到 95.88% Accuracy 和 0.8751 Macro-F1。

EXPERIMENT DESIGN

多序列、多种子和嵌套标签预算

扩展数据包含 1,149 条光谱和 383 个物理样本。围绕类别到达顺序、随机种子、标签预算、强基线和消融因素，完成 240 个核心实验单元与 432 个消融实验单元。

04

可恢复、可审计的产品闭环

LIFECYCLE

标签请求驱动专家更新

两条类别到达序列均完成两个新类别的 R24 注册，每条生命周期记录 48 次 request-confirm 和 8 个模型检查点。标签状态、专家版本和路由结果都可追踪。

PERSISTENCE

模型 Bundle 支持进程重启恢复

保存基础模型、专家注册表、共享仲裁器、比例模型和可见标签状态。Bundle 重载前后固定参考样本预测一致，CLI 提供 prepare、deterministic、live、replay 和 report 入口。

DECISION SUPERVISOR

LLM + RAG 解释模型证据

将模型输出、适用域状态、专家冲突和检索规则组成结构化上下文，完成 24 个真实决策案例。决策动作覆盖 accept、review、abstain 和 request_label。

REPLAY

逐事件日志复现完整决策链

使用 JSONL 记录输入证据、标签可见时间、专家版本、模型路由、知识规则和最终动作。在线结果可离线 Replay，便于定位错误类型和复核实验过程。
