01

一条可追溯的科研回答链路

STEP 01项目上下文

读取研究目标、会话摘要、历史任务与相关记忆。

STEP 02BGE-M3 检索

将问题编码为 1,024 维向量，召回 Claim 与 EvidenceSpan。

STEP 03图谱扩展

连接食品、检测方法、掺假物和化学指标，生成三跳路径。

STEP 04Agent 推理

完成证据整理、跨文献比较、研究方案与答案审阅。

STEP 05Citation 回链

将结论定位至 EvidenceSpan 与原始文献内容。

02

从检索命中到研究判断

HYBRID RAG

向量检索负责召回，知识图谱补足关系

使用 BGE-M3 生成 1,024 维向量，以 NumPy 完成本地相似度检索。命中文献进入 SQLite 图谱后，继续扩展食品、方法、掺假物和指标关系，形成最多三跳的结构化证据路径。

EVIDENCE DESIGN

结论、推论和建议分层组织

将文献事实、跨证据推论、模型背景知识和研究建议分开表达。涉及具体研究结论时绑定 EvidenceSpan Citation，研究者可直接回到支撑片段核验上下文。

AGENT ORCHESTRATION

按任务复杂度切换 Single / Multi Agent

Single 模式处理快速研究问答；Multi 模式拆分证据整理、图谱分析、跨文献综合、研究方案、审阅与修订。两种模式共用模型、知识库和检索工具，便于对照评测。

PROJECT MEMORY

把一次问答接回持续研究过程

项目记忆保存研究目标、会话摘要、相关任务和历史分析，与文献知识库分开管理。每次回答前构建项目上下文，回答后更新研究进展，支持连续追问和方案迭代。

03

用受控实验检验科研辅助价值

EVALUATION SET

80 道中文领域问题，覆盖六类研究任务

题目覆盖单篇事实、方法指标、跨文献比较、证据冲突、研究方案和不可回答判断。围绕同一题集设计 9 组基线与消融实验，每组重复运行 3 次。

把回答质量拆成可比较指标

使用事实正确性、推理深度、研究启发性、Citation 支持率与 RAGAS 评价回答，结合问题级配对统计、Bootstrap 置信区间、Wilcoxon 检验和 Holm 校正分析差异。

04

科研工作台与工程交付

CONTROLLED ANALYSIS

从数据上传走到统计建模

受控 Python 工作流支持数据识别、分析计划、统计检验、机器学习建模和结果归档。在 178 个样本、13 项化学特征的葡萄品种案例中，逻辑回归 balanced accuracy 达到 0.9838 ± 0.0153，XGBoost 达到 0.9632 ± 0.0313。

RESEARCH FIGURES

分析结果直接进入图件流程

建立 source-data、draft、nature、QA 四阶段图件流程，输出 SVG、PDF、TIFF 和 PNG，并生成双语图注。图件保留数据来源与分析任务记录，便于论文材料复核。

DELIVERY

本地化部署与多端验收

后端采用 FastAPI 与 SQLite，前端使用 Vue 3、TypeScript 和 Cytoscape。完成 318 项测试、Docker 部署，以及桌面端和移动端验收。

DATA ASSET

统一管理文献、证据和实体关系

600 个来源身份去重为 593 个唯一内容，Claim、EvidenceSpan、向量和图谱边使用统一标识关联。问答、分析任务与项目记忆分别落库，便于检索和复盘。
