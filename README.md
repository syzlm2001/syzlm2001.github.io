# 陈琳锋个人作品集

静态单页作品集，展示食品 × AI 项目、比赛经历、能力与公开仓库。

## 本地预览

```powershell
python -m http.server 4173 --directory portfolio
```

打开 <http://localhost:4173>。

## GitHub Pages 部署

1. 新建公开仓库 `syzlm2001.github.io`。
2. 将本目录内容放入仓库根目录并推送到 `main` 分支。
3. 在 `Settings → Pages` 选择 `Deploy from a branch`、`main` 分支和根目录。
4. 访问 <https://syzlm2001.github.io>。

站点不依赖后端或外部 CDN；所有照片和图标均为本地资源。
